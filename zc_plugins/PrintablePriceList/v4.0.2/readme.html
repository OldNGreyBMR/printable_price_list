Welcome to the wiki for the Zen Cart Printable Price List (aka PPL) plugin. v4.0.0 and later provide the plugin's file-set using the Zen Cart encapsulated methods to make installation, updates and removals much easier. The plugin's pricelist page's formatting has been validated with the built-in responsive_classic and ZCA Bootstrap templates. v4.0.0 operates slightly differently than previous versions of PPL. Instead of using a totally-separate (and styled) pop-up page, the pricelist page is now loaded by your site's active template's common processing. What this means to you is The pricelist page's formatting uses the 'base' styling provided by your site's active template. You can more easily override PPL's default styling by copying its .css files to the site's template's /css sub-directory: profile-base.css profile-1.css profile-2.css profile-3.css
